# אתר תדמית - רינת ליפשיץ

אתר תדמית עבור רינת ליפשיץ, מטפלת בעיסוי בקליניקה פרטית לנשים בבנימינה.

## על העסק

רינת ליפשיץ מטפלת בנשים בלבד, בקליניקה פרטית בבנימינה, ומציעה את הטיפולים הבאים:

- עיסוי שוודי
- אבנים חמות
- שיאצו
- כוסות רוח
- טיפול לנשים בהריון

## מבנה הפרויקט

- `index.html` - עמוד הבית (עמוד יחיד, RTL, בעברית) הכולל: hero, רשימת טיפולים, אודות המטפלת, מיקום הקליניקה ופרטי יצירת קשר.

## הרצה מקומית

פשוט לפתוח את `index.html` בדפדפן, אין תלות בבנייה או שרת.
